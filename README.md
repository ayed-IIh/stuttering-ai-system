# Stuttering AI System

This project builds an AI system that detects stuttering patterns from speech recordings using machine learning.

## Tech Stack

AI: PyTorch, Torchaudio  
Backend: FastAPI  
Database: PostgreSQL  
Cloud: AWS

## Project Goal

Detect different types of stuttering from speech audio (.wav files).
